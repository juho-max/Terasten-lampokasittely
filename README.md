# Terästen lämpökäsittelyt – tehtävät

Selaimessa toimiva tehtäväsarja Materiaalitekniikan opintojakson lämpökäsittelyosioon (noin 60 min, 9 tehtävää).

- Valinta- ja lukutehtävät tarkistetaan heti, ja jokaisesta vastauksesta näytetään perustelu.
- Avoimissa kohdissa opiskelija kirjoittaa ensin oman vastauksensa ja vertaa sitä mallivastaukseen.
- Vastaukset tallentuvat vain opiskelijan omaan selaimeen (localStorage). Mitään ei lähetetä palvelimelle.
- Sivu on yksi tiedosto (`index.html`) ilman ulkoisia riippuvuuksia.

## Julkaisu GitHub Pagesissa

1. Luo uusi repositorio GitHubissa (esim. `lampokasittely-tehtavat`) ja lataa siihen `index.html` ja `README.md` (*Add file → Upload files*).
2. Avaa *Settings → Pages*.
3. Valitse *Source*-kohtaan *Deploy from a branch*, haaraksi `main` ja kansioksi `/ (root)`. Tallenna.
4. Sivu ilmestyy minuutin parin kuluttua osoitteeseen `https://<käyttäjänimi>.github.io/lampokasittely-tehtavat/`.

## Huomioita opettajalle

- Mallivastaukset näkyvät opiskelijalle Tarkista-painikkeen jälkeen, joten sivu sopii itseopiskeluun ja kertaukseen, ei arvioitavaksi kokeeksi. Pisteytetty opettajan versio on erillisessä asiakirjassa.
- Tehtävän 4 Jominy-arvot on laadittu harjoitusta varten. Lämpötilat ja kovuudet ovat suuntaa antavia; tarkista ne käyttämienne terästen valmistajan aineistoista.
- Tehtävädata on `index.html`-tiedoston `PARTS`-taulukossa, jota voi muokata suoraan.
